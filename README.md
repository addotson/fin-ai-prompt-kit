# Institutional Finance Charts: Multi-Stage Prompt Kit

This kit is five prompts you run in order with an AI chat tool to turn an institution's audited financial statements (and, optionally, a unit's budget and actuals) into a checked JSON database, 12 standard finance charts, and an interactive HTML dashboard. Stage 1 takes an inventory of the files, Stage 2 extracts the data to JSON, Stage 3 is your own review and corrections, Stage 4 draws the charts, and Stage 5 builds the dashboard. The site at https://addotson.github.io/fin-ai-prompt-kit/ shows the whole kit, with a Copy button and a .txt download for each prompt (the files are also in `prompts/`). `kit.md` is the source; `python3 build.py` regenerates the site and `python3 verify.py` checks that every prompt matches `kit.md` byte for byte. Do not commit institutional financial files to this repo.
