# Institutional Finance Charts: Multi-Stage Prompt Kit

This kit is a set of prompts you run in order with an AI chat tool to turn an institution's audited financial statements (any number of years and, optionally, a unit's budget and actuals) into a checked JSON database, 12 standard finance charts, and an interactive HTML dashboard. Stage 1 proves how much of each file the tool can read and maps every fiscal year from the printed column headings, Stage 2 extracts each file into a small JSON fragment, Stage 3 merges the fragments on a browser-only merge page that cross-checks years appearing in two reports, Stage 4 draws the charts, and Stage 5 builds the dashboard. The site at https://addotson.github.io/fin-ai-prompt-kit/ shows the whole kit with a Copy button and a .txt download for each prompt (also in `prompts/`), and the merge page is at https://addotson.github.io/fin-ai-prompt-kit/merge.html. `kit.md` is the source; `python3 build.py` regenerates the site and `python3 verify.py` checks that every prompt matches `kit.md` byte for byte and runs the merge-page tests on synthetic data. Do not commit institutional financial files to this repo.
