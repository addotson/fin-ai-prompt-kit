# Institutional Finance Charts: Multi-Stage Prompt Kit

This kit is a set of prompts you run in order with an AI chat tool, using nothing but the tool and your own files, to turn an institution's audited financial statements (any number of years and, optionally, a unit's budget and actuals) into a checked JSON database, 12 standard finance charts, and an interactive HTML dashboard. Stage 1 proves how much of each file the tool can read and maps every fiscal year from the printed column headings; Stage 2 extracts each file into a downloadable JSON fragment, then merges them with code into a downloadable `database.json`, cross-checking years that appear in two reports; Stage 3 is your review and corrections; Stages 4 and 5 read the uploaded `database.json` to draw the charts and build the dashboard. The site at https://addotson.github.io/fin-ai-prompt-kit/ shows the whole kit with a Copy button and a .txt download for each prompt (also in `prompts/`). `kit.md` is the source; `python3 build.py` regenerates the site and `python3 verify.py` checks that every prompt matches `kit.md` byte for byte. Do not commit institutional financial files to this repo.
